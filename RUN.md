# Как запустить

Нужен Python 3.9 или новее. На этой машине команда называется `python3`. Отдельные пакеты не ставятся, хватает стандартной библиотеки.

```bash
python3 report.py --as-of 2026-11-10 --data data --out out
```

- `--as-of` — дата отчёта, формат `ГГГГ-ММ-ДД` или `ДД.ММ.ГГГГ`. По умолчанию `2026-11-10`.
- `--data` — папка с `contracts.csv`, `works.csv` и `payments.csv`. По умолчанию `data`.
- `--out` — папка для CSV отчёта. По умолчанию `out`. С `--data` совпадать не должна.

Журнал шагов пишется в stderr. Отчёт — два файла в `--out`:

- `works.csv` — по каждой работе: цена, выплачено, осталось, переплата.
- `contracts.csv` — итог договора: живой объём, ушло денег, свободный аванс, остаток, очередь.

Разделитель — запятая, суммы с точкой, кодировка UTF-8 с BOM. Код 0 — оба файла записаны. Код 2 — аргументы не разобрались. Код 1 — нет файла, пустой файл, нет прав, битая строка CSV или папка отчёта совпадает с папкой данных.
